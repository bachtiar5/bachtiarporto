# Icon sources

- Roblox Studio, Luau, Discord, OpenAI (ChatGPT), and Google Gemini brand marks: [Simple Icons](https://simpleicons.org/), downloaded from the Simple Icons npm distribution. Brand marks remain subject to their owners' trademarks.
- Trees, Panels Top Left, Earth, Notebook Pen, Puzzle, and Code XML: [Lucide](https://github.com/lucide-icons/lucide), ISC license. These illustrate disciplines, which have no official brand logo.
- SVG files are stored locally to avoid an external image dependency at runtime.

The original Lucide copyright and license notice is retained in [LUCIDE-LICENSE.txt](LUCIDE-LICENSE.txt).
