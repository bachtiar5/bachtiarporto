## Content and updates

The website supports English and Indonesian. English is the default for new visitors, and saved language choices are remembered.

GitHub Actions refreshes public Roblox snapshots and deploys the website every six hours, as well as on pushes to `main`. Public statistics show their capture date. Developer credits, acknowledgements, project roles, and historical peak CCU are maintained separately from the API snapshots.
